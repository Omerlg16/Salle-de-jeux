# Salle de jeux

Application de gestion d'une salle de jeux vidéo (PS4 / PS3) : parties, recettes, dépenses, contrôle de caisse, dettes des propriétaires et bilans hebdomadaires, mensuels, trimestriels et annuels.

## Version actuelle (prototype)

- App web installable sur téléphone, fonctionne hors ligne.
- Trois rôles : super utilisateur, patron, gérant.
- Les données sont stockées sur l'appareil (localStorage). La synchronisation entre comptes arrive dans la prochaine version.

Ouvrir `index.html` dans un navigateur pour l'essayer.
